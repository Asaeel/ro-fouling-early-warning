# Data Source Log

## 1. NREL / U.S. Department of Energy — Experimental Wave Desalination Data
- URL: https://catalog.data.gov/dataset/experimental-wave-desalination-data-with-variable-feed-and-pressure-input
- Access: Public CSV archives; CC BY 4.0 listed on the catalogue.
- Contents: Steady-state, ramping, sinusoidal, and WEC-Sim experimental RO data with varying feed pressure/flow.
- Decision: Suitable for exploring operating-condition effects and testing ingestion/normalization after inspecting the README and column units. Not assumed to contain fouling or cleaning labels.
- Cleaning: Inspect README and units first; parse timestamps if present; remove duplicate timestamps; reject missing required measurements; do not merge separate experiments into a single continuous fouling cycle without evidence.
- Limitation: Dynamic membrane-performance experiments are not necessarily long-term fouling observations.

## 2. Queen's University Belfast — Performance Data of a SWRO arising from Wave Powered Desalinisation
- URL: https://pure.qub.ac.uk/en/datasets/performance-data-of-a-swro-arising-from-wave-powered-desalinisation/
- Access: Public repository record; processed Excel workbooks described on the landing page.
- Contents: Feed/brine/permeate flow, feed/brine pressure, permeate/brine salinity, temperature, recovery, salt rejection; averages over five-minute stable periods.
- Decision: Candidate for testing operating-condition correction and RO performance analysis. Not accepted as a labelled fouling progression dataset without verifying chronological order and fouling/cleaning events.
- Cleaning: Inspect workbook sheets; standardize units (L/min to m3/h if needed; bar; °C; ppm), preserve experiment identifiers, do not join distinct experimental runs into one time series.
- Limitation: Controlled wave-powered experiments are not equivalent to a long-term commercial RO plant.

## 3. Industrial RO fouling study (2026)
- URL: https://www.sciencedirect.com/science/article/pii/S2950263226000451
- Contents: Paper reports six years of SCADA data and fouling diagnostics; data availability is on request.
- Decision: Not used as a direct data file because the data are not publicly downloadable from the landing page.
- Potential next step: Contact authors if time permits.

## 4. Dryad UF pretreatment dataset
- URL: https://datadryad.org/dataset/doi:10.5068/D1310B
- Contents: 422 days of ultrafiltration pretreatment data.
- Decision: Rejected for direct RO fouling model training because UF and RO are different membrane processes and their performance variables/thresholds are not interchangeable.
- Potential use: Separate pretreatment context only, if explicitly labelled.

## 5. Synthetic fallback used by this prototype
- Source: Generated by `src/fouling/synthetic.py`; not a public plant dataset.
- Purpose: Exercise the complete software pipeline when no verified public time-series dataset with RO fouling and cleaning labels is available.
- Assumptions: Daily samples; small sensor noise; feed temperature/pressure/TDS vary; intrinsic normalized flow degrades gradually; two partial cleaning resets occur.
- Use: Software demonstration and unit-test fixture only.
- Limitation: The model's synthetic test metrics do not establish real-world accuracy. Replace with quality-checked plant data before operational use.
